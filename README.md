# mlh_hf26_fun_game

A simple command-line choose-your-own-adventure game.

## Run

```bash
python adventure_game.py
```

## GitHub Pages deployment

This repository also includes a browser-playable static version of the game at `index.html` so it can run on GitHub Pages (no Python server required at runtime).

1. In GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to `main` (or run the **Deploy to GitHub Pages** workflow manually from the **Actions** tab).

After deployment, the game will be available at:

`https://snehaghoshbarsha444.github.io/mlh_hf26_fun_game/`
